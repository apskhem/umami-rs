# Vendored upstream migrations

Copied verbatim from [umami-software/umami](https://github.com/umami-software/umami)
at tag `v3.4.1` (`prisma/migrations/`), under the MIT license in `LICENSE.umami`.

Do not edit these files. Prisma records a SHA-256 checksum of each `migration.sql`,
and keeping them byte-identical lets upstream Umami and umami-rs share one database.

To track a newer upstream release, copy its new migration directories here, register
them in `src/migrate.rs` and bump `UMAMI_VERSION`.
