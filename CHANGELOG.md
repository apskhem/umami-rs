# Changelog

umami-rs takes upstream Umami's major and minor version; the patch number counts
umami-rs's own releases. Each entry names the upstream release it is compatible with.

## 3.4.0

First release, compatible with upstream Umami **3.4.1**: the same Postgres schema
and migrations, JSON API, official tracker script and dashboard (served as a static
build). Where it intentionally differs from upstream, the differences are listed in
each section of the [README](README.md).
